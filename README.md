# ShapeRose

A SwiftUI artwork created using basic Shape components, gradients, lighting and transparency effects.

<!-- Add preview screenshot here -->

## Features

- SwiftUI Shape composition
- ZStack layering
- LinearGradient and RadialGradient
- Red → Blue → Purple → Red-Purple rose gradient
- Semi-transparent leaves and stem
- Lighting and shadow effects
- Colors managed through Assets.xcassets

## Shapes Used

- Rectangle
- Circle
- Ellipse
- Capsule
- RoundedRectangle
- UnevenRoundedRectangle

## Technologies

- Swift
- SwiftUI
- Xcode

## Project Purpose

This project was created as a SwiftUI Shape practice assignment.
